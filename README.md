# Weather-API

🌦 Indian Weather App

A simple and responsive Indian Weather Application built using HTML, CSS, and JavaScript.
This project fetches real-time weather data using the WeatherAPI and displays weather information for Indian cities only.

📌 Project Features

🇮🇳 Shows weather details for Indian cities only

🔍 City search with auto-suggestions

🌡 Displays temperature, condition, humidity, and wind speed

🎨 Background color changes based on temperature

📱 Responsive and clean user interface

⚡ Beginner-friendly and easy-to-understand code

🛠 Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and responsive design

JavaScript (ES6) – API handling and dynamic updates

WeatherAPI – Fetching live weather data

📂 Project Structure
Indian-Weather-App/
│
├── index.html      # Main HTML file
├── style.css       # Styling file
├── script.js       # JavaScript logic
└── README.md       # Project documentation

🚀 How It Works

User enters an Indian city name

App shows city suggestions related to India

On selecting a city, live weather data is fetched

Weather details are displayed on the screen

Background color changes according to temperature

📸 Output Details

City Name

Temperature (°C)

Weather Condition

Humidity (%)

Wind Speed (km/h)

🔑 API Information

This project uses WeatherAPI.

Endpoint:
https://api.weatherapi.com/v1/current.json

Free API key is used for learning purposes.
